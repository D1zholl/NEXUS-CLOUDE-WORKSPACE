Каталог config\
================

instance.json   Порты и публичный URL. Создаётся лаунчером. Можно изменить
                app_port/db_port при остановленном NEXUS.
secrets.json    Сгенерированные пароль PostgreSQL и NEXUS_SECRET.
                Не редактировать и не публиковать. ACL ограничен текущим
                пользователем. Входит в резервные копии.
nexus.toml      Конфигурация backend. Создаётся из шаблона. Лаунчер
                синхронизирует только port/public_url; остальные настройки
                можно менять вручную при остановленном NEXUS.
nexus.env.example  Справочник переменных окружения (не читается автоматически).

Пароль администратора NEXUS здесь не хранится: он хранится в PostgreSQL
в виде Argon2id-хеша.
