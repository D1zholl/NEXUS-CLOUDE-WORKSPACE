## 2. K4 — внешний вид и 3D-фон

* `prefers-reduced-motion: reduce` — `three/engine.ts` не запускает
  `requestAnimationFrame`, а вызывает `renderStaticFrame()`: один шаг
  раскладки кубов/пыли/камеры с `dt = 0`, полный кадр без анимации.
  Подписка на изменение настройки — `lib/motion.ts`; при смене кадр
  перерисовывается без перезагрузки.
* Страницы разделены:
  * `/system/appearance` — тема, акцент `appearance.interface`
    (`cyan/magenta/green/amber`), состояние движения, переход к фону;
  * `/system/background` — прежние параметры 3D-фона.
  * Меню «Аккаунт» содержит оба пункта, профиль ведёт в «3D-фон».
* Per-user фон сохранён (`appearance.background`), акцент — новый per-user ключ
  `appearance.interface` с серверной нормализацией.
* 360 px: меню сворачивается в кнопку, скрываются статус API и раздел хлебных
  крошек, `page-head::before` не создаёт горизонтальную прокрутку.

Фактические прогоны:

```text

npm run e2e:browsers -- e2e/system.spec.ts
  chrome:  5 passed
```

Сценарии: 14 страниц без ошибок консоли; reduced-motion + статичный кадр;
сохранение акцента и `data-accent` после перезагрузки; навигация на 360 px и
переходы в оба раздела. `npm run typecheck` — 0; `npm run test` — **65 passed**
(13 файлов); `npm run build` — 1808 модулей, JS 1 174,69 кБ / gzip 318,44 кБ.

## 4. K6 — задел delta

`docs/MANIFEST.md` §8/§8.1: будущее необязательное поле `delta`, полный файл
как обязательный fallback, проверка SHA-256 полного файла и патча, матрица
совместимости старый/новый клиент и сервер, правило повышения
`schema_version` только при несовместимом изменении. В коде и
`docs/schemas/manifest-1.0.json` поля `delta` нет; схема сохраняет
`additionalProperties: false`.
