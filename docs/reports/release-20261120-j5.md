## 4. Проверка установки из архива

Архив распакован в `%TEMP%\nexus-j5-extract2`, установщик запущен из
распакованного дерева (без сборки, без регистрации службы, чтобы не мешать
рабочему стенду):

```powershell
Expand-Archive dist\nexus-1.0.0-windows-x64.zip -DestinationPath $env:TEMP\nexus-j5-extract2
cd $env:TEMP\nexus-j5-extract2
.\deployment\install-windows.ps1 -SkipBuild -SkipService -SkipAdmin -SkipPortCheck `
    -InstallDir C:\NexusWorkspaceJ5 `
    -DatabaseUrl "postgres://nexus:***@127.0.0.1:5432/nexus_restore_j3"
```

## 6. Как установить из архива

Кратко (полностью — `docs/INSTALL-WINDOWS.md`):

```powershell
Get-FileHash .\nexus-1.0.0-windows-x64.zip -Algorithm SHA256   # сверить с .sha256
Expand-Archive .\nexus-1.0.0-windows-x64.zip -DestinationPath C:\
cd C:\nexus-1.0.0-windows-x64
.\deployment\install-windows.ps1 -SkipBuild `
    -DatabaseUrl "postgres://nexus:ПАРОЛЬ@127.0.0.1:5432/nexus" `
    -AdminPassword "Пароль" -TestServiceControl
```

Затем — Caddy по разделу 4 инструкции (`NSSM`, `certutil`, firewall).
