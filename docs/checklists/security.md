# Чек-лист безопасности NEXUS WORKSPACE

Краткая выжимка из [SECURITY.md](../SECURITY.md). Отмечайте пункты перед
вводом в эксплуатацию и после изменений в аутентификации, ссылках, хранилище
или сетевой конфигурации.

## Конфигурация

- [ ] `NEXUS_SECRET` не короче 32 символов, не равен значению из `.env.example`.
- [ ] `NEXUS_COOKIE_SECURE=true`, если `NEXUS_PUBLIC_URL` использует HTTPS.
- [ ] `DATABASE_URL` использует отдельную роль с минимальными правами.
- [ ] `NEXUS_TRUST_PROXY=true` только за доверенным reverse proxy.
- [ ] Каталог логов и `.env` недоступны другим пользователям Windows.
- [ ] `NEXUS_ENABLE_DOCS` выключен в production.

## Аутентификация и сессии

- [ ] Пароль администратора сменён после первого входа.
- [ ] Минимальная длина пароля соответствует политике (`limits.password_min_length`).
- [ ] Блокировка после неудачных входов включена; порог проверен.
- [ ] Сессии отзываются при смене пароля и блокировке пользователя.
- [ ] CSRF-заголовок обязателен для изменяющих запросов панели.
- [ ] Токены лаунчера имеют срок действия и минимальные scopes.

## Публичные ссылки

- [ ] Пароль передаётся только в теле `POST /public/shares/{token}/unlock`.
- [ ] В URL, Referer и access log нет параметра `password`.
- [ ] Лимит скачиваний не обходится через `Range` (скачивание по тикету).
- [ ] 5 неверных паролей за 15 минут блокируют дальнейшие попытки (`429`).
- [ ] Смена пароля ссылки инвалидирует старые тикеты (привязка к `password_hash`).
- [ ] Ссылки с `authOnly` требуют действующую cookie-сессию.
- [ ] Отозванные и истёкшие ссылки возвращают `404`/`410`, а не файл.

## Файлы и хранилище

- [ ] MIME определяется по содержимому, а не по расширению.
- [ ] Проверка `path traversal`, symlink/junction и UNC-путей включена.
- [ ] Загрузки пишутся в staging и не попадают в память целиком.
- [ ] Параллельные `PATCH` одной загрузки сериализуются.
- [ ] Квоты проверяются на сервере до создания загрузки.
- [ ] Объекты без ссылок удаляются только после `ref_count = 0`.
- [ ] Задача `system.storage.check` выполняется по расписанию.

## HTTP и браузер

- [ ] CSP, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy` включены.
- [ ] CORS содержит только доверенные origins.
- [ ] Ошибки API не раскрывают SQL, пути и внутренние идентификаторы.
- [ ] Ответы с файлами отдаются с `Content-Disposition` и `nosniff`.

## Эксплуатация

- [ ] Резервная копия БД и объектов проверена восстановлением.
- [ ] Аудит содержит входы, смену прав, ссылки и операции с файлами.
- [ ] В журналах нет паролей, токенов и `NEXUS_SECRET`.
- [ ] Запущен только один экземпляр NEXUS на БД (advisory lock).
- [ ] Известные остаточные риски из SECURITY.md §15 приняты владельцем.
