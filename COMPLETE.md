**Дата:** 20.11.2026.
**Источник требований:** `MAIN_PLAN.md` (этапы 0–10, §17).
**Метод:** фактические сборка и прогоны на Windows 11; установленная служба
`NexusWorkspace`, а не только `cargo run`.
**Версия:** 1.0.0 (`backend/Cargo.toml`, `frontend/package.json`,
`nexus.exe --version`).
**Отчёт прогона:** [`docs/reports/release-1.0.0-l2.md`](docs/reports/release-1.0.0-l2.md).
**Финальная приёмка:** [`docs/reports/final-acceptance-20261120-l3-l5.md`](docs/reports/final-acceptance-20261120-l3-l5.md).

> готовность 100% не подтверждена. Финальная матрица содержит подписной блокер,

> необязательные внешние алерты как остающиеся вопросы.

## 0.1. Интеграция с MyLauncher (21.11.2026)

Серверная часть приведена к фактическому протоколу MyLauncher 0.1.0
(`MC-launcher/src-tauri/src/modpack.rs`), код клиента не менялся.

- Реализованы публичные `/api/packs`, `/api/packs/{id}/versions`,
  `/api/packs/{id}/versions/{v}/manifest`, `/api/packs/{id}/icon`,
  `/api/files/sha256:{hex}` с точными именами полей и `manifestVersion: 1`.
- Добавлены каналы `stable`/`beta` и неизменяемый снимок лаунчер-манифеста
  (миграция `0015`). `archived` исключён, `deprecated` доступен по точной
  версии.
- Launcher-ready проверки блокируют публикацию: несовместимый путь/расширение,
  неверная Java, `quilt`, отсутствующий объект, лишний размер.
- Артефакты отдаются потоком, SHA-256 проверяется клиентом, `Range` даёт
  `206`/`416`, скачивания логируются; rate limit — по токену или IP.
- Панель: мастер без Quilt и с точной Java, каналы релизов, точный JSON
  MyLauncher и URL манифеста, карточка «Подключение MyLauncher».
- Токены: stock MyLauncher не умеет их передавать. Публичные сборки работают
  анонимно; приватные доступны только будущим клиентам с Bearer. Ограничение
  зафиксировано в `docs/LAUNCHER_CONTRACT.md`.

**Проверка:** `cargo test -j 2 --no-fail-fast` — **368 passed, 0 failed**;
`cargo clippy --all-targets -- -D warnings`, `cargo fmt --check` — чисто;
`npm run typecheck`, `npm run lint`, `npm run test` (**75 passed**),
`npm run build` — успешно. Реальный запуск MyLauncher с установкой и запуском
Minecraft в этой среде не выполнялся (нужны GUI и лицензия); HTTP-контракт,
Range, каналы, приватность и неизменяемость проверены интеграционными тестами
на PostgreSQL. Подробности — `docs/TESTING.md` §3.3.

## 0. Обновление FIX-PLAN (21.11.2026)

В рамках `FIX-PLAN.md` закрыты:

- **S1–S3**: публичные ссылки скачиваются по короткоживущему HMAC-тикету;
  пароль проверяется в `POST /unlock` и не попадает в URL; лимит скачиваний
  атомарный и не обходится через `Range`; 5 ошибок пароля / 15 минут и
  10 unlock/мин на IP.
- **C1**: параллельные `PATCH` одной загрузки сериализуются, второй получает
  `409 UPLOAD_BUSY`; условный `UPDATE` защищает `received_bytes`.
- **A1**: `minecraft`/`launcher` больше не импортируют `crate::cloud`; общие
  операции перенесены в `storage`, добавлен архитектурный тест.
- **P1**: кэш проверки сессии на 20 секунд и продление не чаще раза в 5 минут;
  инвалидация на logout/revoke/пароль/роли; метрики в мониторинге.
- **P2**: advisory lock `hashtext('nexus.instance')` — второй экземпляр не
  запускается.
- **F2**: `services/api.ts` разделён на `http/types/auth/users/roles/system/
  storage/cloud/minecraft/launcher/publicShare/index`; старый импорт работает.
- **F3**: `app.css` разделён на `base/layout/components/forms/tables/pages/*`
  с сохранением порядка каскада.
- **F4**: ESLint 9 + Prettier, `lint`/`format:check` в `scripts/verify.ps1`.
- **F5**: OpenAPI разложен по доменам; JSON идентичен прежнему (108 путей /
  133 операции, добавлен `POST /public/shares/{token}/unlock`).
- **B1**: `nexus user ...`, `users.bat`, `first-run.bat`, `start.bat`;
  `nexus objects audit|purge-missing` для O1.
- **D1**: `docs/ADMIN_GUIDE.md` разделён на `docs/admin/*`; добавлен
  `docs/checklists/security.md`; `docs/API.md` перегенерирован.

**Проверка:** `cargo check`, `cargo test --no-run`, `cargo fmt`, `clippy`,
`npm run typecheck`, `npm run lint`, `npm run format:check`, `npm run test`
(**64 passed**), `npm run build` — зелёные. Полный `cargo test` требует
PostgreSQL, которого нет в среде выполнения этого обновления; тестовые
бинарники собраны.

F1 (`pages/cloud/`) выполнена частично: страница вынесена в пакет, извлечены
`SharesView`, `FileGlyph` и чистые помощники; полное разбиение на хуки и
модальные компоненты остаётся отдельной задачей.

## 4. Незакрытое и отклонения

### 4.1. BLOCKED / PARTIAL

| Что | Причина | Как закрыть |
|---|---|---|
| Подписанный чек-лист §17 (L3) | Нет подтверждения владельца и несколько пунктов имеют блокирующий или частичный статус | Приложить исходные референсы и выполнить/подписать оставшиеся пункты отчёта L3–L5 |
| Визуальное соответствие главной | Исходники `главная_страница.png` и `форма_входа.png` отсутствуют | Приложить референсы и выполнить визуальное сравнение |
| Чистая установка Windows из ZIP | J5 использовал `-SkipService`, VM-чистого прогона не было | Повторить полный install на чистой Windows 11 |
| Остановка службы во время active PATCH | Есть stop/recovery и client-resume, но не точный одновременный сценарий | Выполнить live-тест с незавершённым PATCH и Resume |
| Операционная стабильность health и объектов | В 5 health-запросах первые 2 вернули down; в БД остаются 6 missing-объектов | Исследовать pool/latency и выполнить restore/purge решениями администратора |
| Внешние алерты | В приложении нет webhook/alert destinations | Настроить алерты по проекту или зафиксировать как принятие риска |

### 4.2. Документированные отклонения

- **25 ГиБ не перезапускался в L2.** Для финальной L2 этого места не хватило; используется прошедший G2-отчёт от 19.11.2026.
- **Delta-обновления манифеста** и шаринг файлов между пользователями отложены и не заявлены как реализованные.
- **SVG-предпросмотр** отключён в inline режиме (XSS); HTML/JS не исполняются inline.
- **L2 использовал loopback.** На время live-smoke cookie secure и PUBLIC_URL временно соответствовали HTTP-loopback; после прогона настройки HTTPS возвращены.

### 4.3. Известные ограничения

- Без ограничения `-j 2` `cargo test`/`clippy` могут упасть на Windows с `os error 1455`.
- `npm ci` может предупреждать об install-script `esbuild`; сборка и тесты проходят.
- `pages/cloud/` декомпозирован частично: контейнер страницы пока больше 300
  строк, дальнейшее разделение на хуки/модальные окна — отдельная задача.
- `cargo test` требует PostgreSQL `nexus_test`; в среде обновления FIX-PLAN
  выполнялась только компиляция тестов (`cargo test --no-run`).
